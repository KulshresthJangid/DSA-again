# Rotate Image

**Pattern**: Transpose + Reverse | **Difficulty**: Medium
**LeetCode**: [#48. Rotate Image](https://leetcode.com/problems/rotate-image/)

---

## Like You're 5
Rotating 90° clockwise = two simpler steps:
1. Transpose (flip along diagonal: swap matrix[i][j] with matrix[j][i])
2. Reverse each row

---

## The Real Problem
Rotate n×n matrix 90° clockwise in-place.

---

## How to Solve It
1. Transpose: for i<j: swap `matrix[i][j]` ↔ `matrix[j][i]`
2. Reverse each row: `row.reverse()`

---

## The One Trick
> "Rotate 90° clockwise = transpose then reverse rows. Memorize this decomposition."

**Time**: O(n²) | **Space**: O(1)
