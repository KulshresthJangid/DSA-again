# Spiral Matrix

**Pattern**: Boundary Simulation | **Difficulty**: Medium

---

## Like You're 5
Peel the matrix like an onion — always take the outermost ring first (left→right, top→bottom, right→left, bottom→top), then shrink the boundaries inward.

---

## The Real Problem
Return all elements of matrix in spiral order.

---

## How to Solve It
```
top, bottom, left, right = 0, rows-1, 0, cols-1
while top<=bottom and left<=right:
    traverse right along top row, then top++
    traverse down along right col, then right--
    traverse left along bottom row (if top<=bottom), then bottom--
    traverse up along left col (if left<=right), then left++
```

---

## The One Trick
> "Four boundaries shrink inward as you peel each layer."

**Time**: O(m×n) | **Space**: O(1)
