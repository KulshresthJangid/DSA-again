# Set Matrix Zeroes

**Pattern**: In-place marking | **Difficulty**: Medium
**LeetCode**: [#73. Set Matrix Zeroes](https://leetcode.com/problems/set-matrix-zeroes/)

---

## Like You're 5
If any cell is 0, the whole row and column must become 0.
But if you zero out rows/columns immediately, you'll create false 0s.
Instead: first scan and mark which rows/columns need zeroing. Then apply.

---

## The Real Problem
Zero out entire row and column of any cell that contains 0 (in-place).

---

## How to Solve It
1. Collect all rows and cols that contain a 0
2. Second pass: zero out those rows and cols

**O(1) space trick**: use first row/col as markers.

---

## The One Trick
> "Never zero while scanning — mark first, apply second."

**Time**: O(m×n) | **Space**: O(1) with markers trick
