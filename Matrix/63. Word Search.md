# Word Search

**Pattern**: DFS Backtracking | **Difficulty**: Medium
**LeetCode**: [#79. Word Search](https://leetcode.com/problems/word-search/)

---

## Like You're 5
Find a word in a letter grid by moving up/down/left/right. You can't revisit a cell.
For each starting cell that matches the first letter, explore all paths. Backtrack if stuck.

---

## The Real Problem
Return true if word exists in grid (adjacent cells, no reuse).

---

## How to Solve It
```
for each cell (r,c):
    if dfs(r, c, 0): return True

def dfs(r, c, idx):
    if idx == len(word): return True
    if out of bounds or visited or grid[r][c]!=word[idx]: return False
    mark visited, explore 4 neighbors, unmark visited (backtrack)
```

---

## The One Trick
> "Mark cell as visited before recursing, unmark after — that's backtracking."

**Time**: O(m×n×4^L) | **Space**: O(L)
