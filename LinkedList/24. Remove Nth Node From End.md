# Remove Nth Node From End of List

**Pattern**: Two Pointers (Fast & Slow) | **Difficulty**: Medium
**LeetCode**: [#19. Remove Nth Node From End](https://leetcode.com/problems/remove-nth-node-from-end-of-list/)

---

## Like You're 5
You want to remove the 2nd node from the end, but you don't know the length.
Send a fast runner ahead by n steps. Then move both at the same speed. When fast hits the end, slow is exactly at the node *before* the one to remove.

---

## The Real Problem
Remove the nth node from the end of a linked list. One pass.

**Example**: `1→2→3→4→5`, n=2 → `1→2→3→5`

---

## How to Solve It
1. Dummy → head. `fast=slow=dummy`
2. Move fast n+1 steps ahead
3. Move both until fast is None
4. `slow.next = slow.next.next`
5. Return dummy.next

---

## The One Trick
> "Gap of n between fast and slow — when fast falls off, slow is right before the target."

**Time**: O(n) | **Space**: O(1)
