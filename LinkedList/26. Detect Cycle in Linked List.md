# Linked List Cycle

**Pattern**: Floyd's Tortoise & Hare | **Difficulty**: Easy
**LeetCode**: [#141. Detect Cycle in Linked List](https://leetcode.com/problems/linked-list-cycle/)

---

## Like You're 5
Two runners on a track — one fast, one slow. If there's a loop, the fast runner will eventually lap the slow one and they'll meet. If there's no loop, the fast runner just falls off the end.

---

## The Real Problem
Return true if linked list has a cycle.

---

## How to Solve It
1. `slow=head`, `fast=head`
2. While fast and fast.next exist:
   - slow = slow.next
   - fast = fast.next.next
   - If slow == fast → cycle exists, return true
3. Return false

---

## The One Trick
> "Fast catches slow in a loop — they're guaranteed to meet if a cycle exists."

**Time**: O(n) | **Space**: O(1)
