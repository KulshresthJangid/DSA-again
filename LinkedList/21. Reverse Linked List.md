# Reverse Linked List

**Pattern**: Iterative Pointer Manipulation | **Difficulty**: Easy
**LeetCode**: [#206. Reverse Linked List](https://leetcode.com/problems/reverse-linked-list/)

---

## Like You're 5
You have a line of kids, each holding the shoulder of the kid in front.
To reverse: one by one, make each kid grab the shoulder of the kid *behind* them instead.
You need three hands: previous, current, next.

---

## The Real Problem
Reverse a singly linked list.

**Example**: `1→2→3→4→5` → `5→4→3→2→1`

---

## How to Solve It
1. `prev=None`, `curr=head`
2. While curr is not None:
   - `next = curr.next`  (save next before breaking link)
   - `curr.next = prev`  (flip the arrow)
   - `prev = curr`
   - `curr = next`
3. Return `prev`

---

## See It Happen
```
prev=None, curr=1
Step1: next=2, 1.next=None, prev=1, curr=2
Step2: next=3, 2.next=1,    prev=2, curr=3
Step3: next=4, 3.next=2,    prev=3, curr=4
Step4: next=5, 4.next=3,    prev=4, curr=5
Step5: next=None,5.next=4,  prev=5, curr=None
Return 5 ✓
```

---

## The One Trick
> "Three variables: prev, curr, next. Save next, flip arrow, slide forward."

**Time**: O(n) | **Space**: O(1)
