# Serialize and Deserialize Binary Tree

**Pattern**: BFS or DFS encoding | **Difficulty**: Hard

---

## Like You're 5
Turn a tree into a string (serialize), then rebuild it from that string (deserialize).
Use preorder: write values separated by commas, use "N" for null nodes.

---

## The Real Problem
Design encode (tree→string) and decode (string→tree).

---

## How to Solve It
**Serialize** (preorder DFS): visit root, left, right. Null → "N"
**Deserialize**: split by comma into queue. Build node from first element, recurse left and right.

---

## The One Trick
> "Preorder DFS naturally encodes structure. Null markers let you reconstruct exactly."

**Time**: O(n) | **Space**: O(n)
