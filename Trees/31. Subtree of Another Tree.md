# Subtree of Another Tree

**Pattern**: DFS + isSameTree | **Difficulty**: Easy
**LeetCode**: [#572. Subtree of Another Tree](https://leetcode.com/problems/subtree-of-another-tree/)

---

## Like You're 5
Is the small tree hiding somewhere inside the big tree?
Check every node in the big tree: "does the subtree starting here look exactly like the small tree?"

---

## The Real Problem
Return true if tree t is a subtree of tree s.

---

## How to Solve It
1. At every node in s, call `isSameTree(s_node, t)`
2. If any returns true → return true
3. Else recurse left and right of s

---

## The One Trick
> "Reuse isSameTree at every node. Two classic problems combined."

**Time**: O(m×n) | **Space**: O(h)
