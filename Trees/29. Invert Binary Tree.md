# Invert Binary Tree

**Pattern**: DFS Recursion | **Difficulty**: Easy
**LeetCode**: [#226. Invert Binary Tree](https://leetcode.com/problems/invert-binary-tree/)

---

## Like You're 5
Mirror a tree — every left child swaps with its right child.
Do it top down: swap current node's children, then recursively invert each child.

---

## The Real Problem
Flip a binary tree (mirror it left-right).

---

## How to Solve It
```
def invertTree(root):
    if not root: return None
    root.left, root.right = root.right, root.left
    invertTree(root.left)
    invertTree(root.right)
    return root
```

---

## The One Trick
> "Swap children at every node. That's literally the whole algorithm."

**Time**: O(n) | **Space**: O(h)
