# Lowest Common Ancestor of BST

**Pattern**: BST Property | **Difficulty**: Medium

---

## Like You're 5
In a BST, everything left is smaller, everything right is bigger.
Start at root. If both p and q are smaller → go left. If both bigger → go right. If they split (one left, one right) — you're at the ancestor!

---

## The Real Problem
Find the lowest common ancestor of two nodes in a BST.

---

## How to Solve It
```
while root:
    if p.val < root.val and q.val < root.val:
        root = root.left
    elif p.val > root.val and q.val > root.val:
        root = root.right
    else:
        return root
```

---

## The One Trick
> "When p and q are on different sides of a node — that node is their LCA."

**Time**: O(h) | **Space**: O(1)
