# Validate Binary Search Tree

**Pattern**: DFS with bounds | **Difficulty**: Medium
**LeetCode**: [#98. Validate Binary Search Tree](https://leetcode.com/problems/validate-binary-search-tree/)

---

## Like You're 5
A BST rule: every node must be bigger than everything to its left AND smaller than everything to its right (not just its direct parent).
Pass down a min and max boundary to every node. The node must be between them.

---

## The Real Problem
Return true if tree is a valid BST.

---

## How to Solve It
```
def isValid(node, min_val=-inf, max_val=inf):
    if not node: return True
    if node.val <= min_val or node.val >= max_val: return False
    return isValid(node.left, min_val, node.val) and            isValid(node.right, node.val, max_val)
```

---

## The One Trick
> "Pass boundaries down. Left child's max = parent's value. Right child's min = parent's value."

**Time**: O(n) | **Space**: O(h)
