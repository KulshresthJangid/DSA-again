# Construct Tree from Preorder and Inorder Traversal

**Pattern**: Recursion + Divide | **Difficulty**: Medium

---

## Like You're 5
Preorder: root comes first. So first element of preorder = root.
Find that root in inorder — everything left of it is left subtree, everything right is right subtree.
Recurse on those halves.

---

## The Real Problem
Build a binary tree from preorder and inorder traversal arrays.

**Example**: preorder=`[3,9,20,15,7]`, inorder=`[9,3,15,20,7]` → tree with root 3

---

## How to Solve It
1. Root = preorder[0]
2. Find root in inorder → index i
3. Left subtree size = i elements
4. Recurse: left = build(preorder[1:i+1], inorder[:i])
5. Recurse: right = build(preorder[i+1:], inorder[i+1:])

---

## The One Trick
> "Preorder tells you the root. Inorder tells you how to split left/right."

**Time**: O(n²) naive, O(n) with hashmap | **Space**: O(n)
