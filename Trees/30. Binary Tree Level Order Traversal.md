# Binary Tree Level Order Traversal

**Pattern**: BFS with Queue | **Difficulty**: Medium
**LeetCode**: [#102. Binary Tree Level Order Traversal](https://leetcode.com/problems/binary-tree-level-order-traversal/)

---

## Like You're 5
Visit a tree floor by floor. Use a queue (waiting line). Process everyone on the current floor, then add their children to the queue for the next floor.

---

## The Real Problem
Return node values level by level as a list of lists.

**Example**: `[[3],[9,20],[15,7]]`

---

## How to Solve It
1. Queue = [root]
2. While queue not empty:
   - For each node in current level: dequeue, record value, enqueue children
   - Append level values to result

---

## The One Trick
> "BFS = queue. Snapshot the queue size at start of each level — process exactly that many nodes."

**Time**: O(n) | **Space**: O(n)
