# Binary Tree Maximum Path Sum

**Pattern**: DFS with global max | **Difficulty**: Hard

---

## Like You're 5
A path in a tree goes through some nodes without backtracking. You want the path with the highest sum. The tricky part: a path can go up through a node then down — forming an arch.
At every node, compute the best arch through it. Track the global best.

---

## The Real Problem
Find the maximum sum of any path in the binary tree (path can start/end at any node).

---

## How to Solve It
```
result = [root.val]

def dfs(node):
    if not node: return 0
    leftMax = max(dfs(node.left), 0)   # ignore negatives
    rightMax = max(dfs(node.right), 0)
    result[0] = max(result[0], node.val + leftMax + rightMax)  # arch
    return node.val + max(leftMax, rightMax)  # single path upward

dfs(root)
return result[0]
```

---

## The One Trick
> "At every node: arch = left + node + right (update global max). But return only one side to parent."

**Time**: O(n) | **Space**: O(h)
