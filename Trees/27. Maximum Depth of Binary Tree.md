# Maximum Depth of Binary Tree

**Pattern**: DFS Recursion | **Difficulty**: Easy

---

## Like You're 5
A tree is like a family tree. The depth is how many generations deep it goes.
To find the deepest level: ask the left branch "how deep are you?" and ask the right branch the same. Take the bigger answer, add 1 for yourself.

---

## The Real Problem
Return the height of a binary tree.

**Example**: Tree with root 3, left subtree depth 2, right subtree depth 1 → `3`

---

## How to Solve It
```
def maxDepth(root):
    if not root: return 0
    return 1 + max(maxDepth(root.left), maxDepth(root.right))
```

---

## The One Trick
> "Depth = 1 + max(left depth, right depth). Base case: empty node returns 0."

**Time**: O(n) | **Space**: O(h) — h = tree height
