# Kth Smallest Element in a BST

**Pattern**: Inorder Traversal | **Difficulty**: Medium

---

## Like You're 5
Inorder traversal of a BST visits nodes in sorted order (left → root → right).
Just do inorder and stop at the kth node.

---

## The Real Problem
Find the kth smallest value in a BST.

---

## How to Solve It
1. Inorder traversal (left, root, right)
2. Count nodes visited
3. When count == k, return that node's value

---

## The One Trick
> "BST inorder = sorted sequence. Kth smallest = stop at kth inorder visit."

**Time**: O(h+k) | **Space**: O(h)
