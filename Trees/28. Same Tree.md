# Same Tree

**Pattern**: DFS Recursion | **Difficulty**: Easy
**LeetCode**: [#100. Same Tree](https://leetcode.com/problems/same-tree/)

---

## Like You're 5
Two trees are identical if every node at every position has the same value.
Compare the roots. If same, compare left subtrees, compare right subtrees. All must match.

---

## The Real Problem
Return true if two binary trees are structurally identical with same values.

---

## How to Solve It
```
def isSameTree(p, q):
    if not p and not q: return True
    if not p or not q: return False
    if p.val != q.val: return False
    return isSameTree(p.left, q.left) and isSameTree(p.right, q.right)
```

---

## The One Trick
> "Three base cases: both null (true), one null (false), values differ (false). Then recurse."

**Time**: O(n) | **Space**: O(h)
