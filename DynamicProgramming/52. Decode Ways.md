# Decode Ways

**Pattern**: DP | **Difficulty**: Medium

---

## Like You're 5
Letters are encoded as numbers: A=1, B=2 ... Z=26.
Given a string of digits, how many ways can you decode it?
At each position, you can take 1 digit (if valid) or 2 digits (if 10-26). Count both paths.

---

## The Real Problem
Count decoding ways for a digit string.

**Example**: `"226"` → `3` (2,2,6 | 22,6 | 2,26)

---

## How to Solve It
```
dp[0]=1, dp[1]= 0 if s[0]=='0' else 1
for i in 2..n:
    one_digit = int(s[i-1])
    two_digit = int(s[i-2:i])
    if 1<=one_digit<=9: dp[i] += dp[i-1]
    if 10<=two_digit<=26: dp[i] += dp[i-2]
return dp[n]
```

---

## The One Trick
> "Two choices at each step: take 1 digit or take 2. Both must be valid (no leading zeros, no >26)."

**Time**: O(n) | **Space**: O(n) → O(1) optimized
