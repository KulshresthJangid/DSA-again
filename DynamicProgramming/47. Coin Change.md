# Coin Change

**Pattern**: DP (Bottom-Up) | **Difficulty**: Medium

---

## Like You're 5
You have coins of different values and want to make exactly $11 using fewest coins.
Build up from $0: to make $11, try every coin. Min coins for $11 = 1 + min coins for (11 - coin_value).

---

## The Real Problem
Minimum coins to make amount. Return -1 if impossible.

**Example**: coins=`[1,5,6,9]`, amount=11 → `2` (5+6)

---

## How to Solve It
```
dp = [inf] * (amount+1)
dp[0] = 0
for amt in range(1, amount+1):
    for coin in coins:
        if coin <= amt:
            dp[amt] = min(dp[amt], 1 + dp[amt-coin])
return dp[amount] if dp[amount] != inf else -1
```

---

## The One Trick
> "Build the answer for every amount from 0 to target. Each answer builds on smaller answers."

**Time**: O(amount × coins) | **Space**: O(amount)
