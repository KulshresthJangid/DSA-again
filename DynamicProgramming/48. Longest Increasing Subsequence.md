# Longest Increasing Subsequence

**Pattern**: DP | **Difficulty**: Medium

---

## Like You're 5
Find the longest chain of numbers where each one is bigger than the previous (they don't need to be adjacent).
For each number, find the longest chain that can END at this number.

---

## The Real Problem
Return length of longest strictly increasing subsequence.

**Example**: `[10,9,2,5,3,7,101,18]` → `4` (2,3,7,101 or 2,5,7,101)

---

## How to Solve It
```
dp = [1] * n   # every number is a chain of length 1 by itself
for i in range(n):
    for j in range(i):
        if nums[j] < nums[i]:
            dp[i] = max(dp[i], dp[j]+1)
return max(dp)
```

---

## The One Trick
> "For each element, ask every previous smaller element: 'what's the longest chain you end?' Add 1."

**Time**: O(n²) — O(n log n) with patience sort | **Space**: O(n)
