# Longest Common Subsequence

**Pattern**: 2D DP | **Difficulty**: Medium
**LeetCode**: [#1143. Longest Common Subsequence](https://leetcode.com/problems/longest-common-subsequence/)

---

## Like You're 5
Find the longest sequence of characters that appears in both strings in order (not necessarily contiguous).
"ABCDE" and "ACE" → "ACE" (length 3).
Build a table: if chars match, take diagonal+1. If not, take max of left or up.

---

## The Real Problem
Return length of longest common subsequence of two strings.

**Example**: `"abcde"`, `"ace"` → `3`

---

## How to Solve It
```
dp[i][j] = LCS of s1[:i] and s2[:j]
if s1[i-1]==s2[j-1]: dp[i][j] = dp[i-1][j-1] + 1
else: dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

---

## The One Trick
> "Match → extend diagonal. No match → take best of top or left."

**Time**: O(m×n) | **Space**: O(m×n)
