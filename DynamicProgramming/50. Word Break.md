# Word Break

**Pattern**: DP | **Difficulty**: Medium
**LeetCode**: [#139. Word Break](https://leetcode.com/problems/word-break/)

---

## Like You're 5
Can you split "leetcode" into words from a dictionary?
Try every possible split point. If the left part is a valid word AND the right part can also be split — it works.

---

## The Real Problem
Return true if string can be segmented into dictionary words.

**Example**: `"leetcode"`, dict=`["leet","code"]` → `true`

---

## How to Solve It
```
dp = [False] * (n+1)
dp[0] = True   # empty string
for i in range(1, n+1):
    for j in range(i):
        if dp[j] and s[j:i] in wordSet:
            dp[i] = True
            break
return dp[n]
```

---

## The One Trick
> "dp[i] = True if any split s[0:j] + s[j:i] works where dp[j] is already True."

**Time**: O(n²) | **Space**: O(n)
