# Combination Sum IV

**Pattern**: DP (order matters) | **Difficulty**: Medium

---

## Like You're 5
How many ways can you add numbers from a list to reach a target? Order matters (1+2 and 2+1 are different).
For each target amount, sum up ways to reach (target - each_num).

---

## The Real Problem
Count combinations (ordered) of nums that sum to target.

**Example**: `nums=[1,2,3]`, target=4 → `7`

---

## How to Solve It
```
dp = [0] * (target+1)
dp[0] = 1
for i in range(1, target+1):
    for num in nums:
        if i >= num:
            dp[i] += dp[i-num]
return dp[target]
```

---

## The One Trick
> "Outer loop = amounts, inner loop = nums. This counts ordered sequences (unlike coin change which counts sets)."

**Time**: O(target × nums) | **Space**: O(target)
