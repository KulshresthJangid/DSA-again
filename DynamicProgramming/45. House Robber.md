# House Robber

**Pattern**: Dynamic Programming | **Difficulty**: Medium
**LeetCode**: [#198. House Robber](https://leetcode.com/problems/house-robber/)

---

## Like You're 5
You can't rob two houses in a row (alarm triggers). For each house, decide: rob it (add its value + best from 2 houses ago) or skip it (keep best from previous house). Take the max.

---

## The Real Problem
Max money from non-adjacent houses.

**Example**: `[2,7,9,3,1]` → `12` (rob 2, 9, 1)

---

## How to Solve It
```
prev2, prev1 = 0, 0
for num in nums:
    curr = max(prev1, prev2 + num)
    prev2, prev1 = prev1, curr
return prev1
```

---

## The One Trick
> "At each house: `max(skip, rob_this + best_two_back)`. Track only last two values."

**Time**: O(n) | **Space**: O(1)
