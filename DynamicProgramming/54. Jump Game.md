# Jump Game

**Pattern**: Greedy | **Difficulty**: Medium

---

## Like You're 5
You're on tiles. Each tile says how far you can jump. Can you reach the last tile?
Track the farthest point you can reach. If you're ever at a tile you can't reach — stuck.

---

## The Real Problem
Given jump lengths at each index, return true if you can reach the last index.

**Example**: `[2,3,1,1,4]` → `true` | `[3,2,1,0,4]` → `false`

---

## How to Solve It
```
maxReach = 0
for i, jump in enumerate(nums):
    if i > maxReach: return False
    maxReach = max(maxReach, i + jump)
return True
```

---

## The One Trick
> "Track max reachable index. If current index exceeds it — you're stranded."

**Time**: O(n) | **Space**: O(1)
