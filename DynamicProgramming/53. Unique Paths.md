# Unique Paths

**Pattern**: 2D DP | **Difficulty**: Medium
**LeetCode**: [#62. Unique Paths](https://leetcode.com/problems/unique-paths/)

---

## Like You're 5
A robot on a grid can only move right or down. How many paths from top-left to bottom-right?
Paths to any cell = paths from cell above + paths from cell to the left. Fill the grid.

---

## The Real Problem
Count unique paths in m×n grid from top-left to bottom-right.

---

## How to Solve It
```
dp[0][j] = 1 for all j (top row — only one way: go right)
dp[i][0] = 1 for all i (left col — only one way: go down)
for i,j: dp[i][j] = dp[i-1][j] + dp[i][j-1]
return dp[m-1][n-1]
```

---

## The One Trick
> "Every cell = paths from above + paths from left. The top row and left column are all 1s."

**Time**: O(m×n) | **Space**: O(m×n) → O(n) with rolling row
