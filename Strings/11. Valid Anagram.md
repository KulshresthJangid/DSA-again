# Valid Anagram

**Pattern**: Hash Map / Frequency Count | **Difficulty**: Easy
**LeetCode**: [#242. Valid Anagram](https://leetcode.com/problems/valid-anagram/)

---

## Like You're 5
Two words are anagrams if they use exactly the same letters, just shuffled.
"eat" and "tea" — same letters! Count each letter in both words. If counts match, it's an anagram.

---

## The Real Problem
Return true if s and t are anagrams of each other.

**Example**: `s="anagram"`, `t="nagaram"` → `true`

---

## How to Solve It
1. If lengths differ → false
2. Count character frequencies in s (map)
3. For each char in t: decrement its count
4. If any count ≠ 0 → false. Otherwise → true

---

## The One Trick
> "Same letters, same counts. One map, increment for s, decrement for t, check all zeros."

**Time**: O(n) | **Space**: O(1) (26 letters max)
