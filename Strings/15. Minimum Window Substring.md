# Minimum Window Substring

**Pattern**: Sliding Window | **Difficulty**: Hard

---

## Like You're 5
You need to find the shortest section of a long sentence that contains all letters from a target word.
Expand your window right until you have all needed letters. Then shrink from left to make it as small as possible. Record that size. Repeat.

---

## The Real Problem
Find the smallest substring of s that contains all characters of t.

**Example**: `s="ADOBECODEBANC"`, `t="ABC"` → `"BANC"`

---

## How to Solve It
1. Count chars needed (`need` map from t)
2. `left=0`, `formed=0`, `required=len(need)`, `window={}`
3. Expand right: add char to window, if window[c]==need[c] → formed++
4. While formed==required: record window, shrink from left
5. Return smallest recorded window

---

## The One Trick
> "Expand until valid, then shrink as far as possible. That's your candidate. Repeat."

**Time**: O(s+t) | **Space**: O(s+t)
