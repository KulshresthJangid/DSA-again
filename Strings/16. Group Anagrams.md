# Group Anagrams

**Pattern**: Hash Map + Sorted Key | **Difficulty**: Medium

---

## Like You're 5
Sort each word's letters alphabetically — anagrams will become identical.
"eat" → "aet", "tea" → "aet" — same key! Group by that sorted key.

---

## The Real Problem
Group anagrams together from a list of words.

**Example**: `["eat","tea","tan","ate","nat","bat"]` → `[["eat","tea","ate"],["tan","nat"],["bat"]]`

---

## How to Solve It
1. `map = {}`
2. For each word: `key = sorted(word)` (as tuple/string)
3. Append word to `map[key]`
4. Return map values

---

## The One Trick
> "Sorted letters are the fingerprint of an anagram group."

**Time**: O(n·k·log k) | **Space**: O(n·k)
