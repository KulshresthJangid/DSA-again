# Valid Palindrome

**Pattern**: Two Pointers | **Difficulty**: Easy

---

## Like You're 5
"racecar" reads the same forwards and backwards.
Put one finger at the start and one at the end. Move them toward each other, comparing as you go. If they ever don't match — not a palindrome.

---

## The Real Problem
Given a string (with non-alphanumeric chars), check if it's a palindrome (ignore case, ignore non-alphanumeric).

**Example**: `"A man, a plan, a canal: Panama"` → `true`

---

## How to Solve It
1. `left=0`, `right=end`
2. While left < right:
   - Skip non-alphanumeric on both sides
   - If `lower(s[left]) != lower(s[right])` → false
   - left++, right--
3. Return true

---

## The One Trick
> "Two pointers, skip noise, compare letters only."

**Time**: O(n) | **Space**: O(1)
