# Longest Repeating Character Replacement

**Pattern**: Sliding Window | **Difficulty**: Medium

---

## Like You're 5
You have a string and can change at most k letters. Find the longest stretch where one letter dominates.
In any window, if `window size - count of most frequent letter ≤ k`, you can fix the rest. Expand the window. When it breaks, slide forward.

---

## The Real Problem
Given string and k replacements, find length of longest substring with all same chars after ≤k replacements.

**Example**: `s="AABABBA"`, `k=1` → `4`

---

## How to Solve It
1. `left=0`, `maxCount=0`, `counts={}`, `result=0`
2. For each right:
   - Increment `counts[s[right]]`
   - `maxCount = max(maxCount, counts[s[right]])`
   - Window invalid if `(right-left+1) - maxCount > k` → shrink: decrement `counts[s[left]]`, left++
   - `result = max(result, right-left+1)`

---

## The One Trick
> "Window is valid if replacements needed = (window size - most frequent count) ≤ k."

**Time**: O(n) | **Space**: O(1)
