# Valid Parentheses

**Pattern**: Stack | **Difficulty**: Easy

---

## Like You're 5
Every time you open a door, write it down. Every time you close a door, the last opened door must match.
Stack = your notepad. Push opens, pop and verify closes.

---

## The Real Problem
Return true if brackets are correctly matched and nested: `()[]{}`.

**Example**: `"()[]{}"` → `true`, `"(]"` → `false`

---

## How to Solve It
1. Stack = []
2. For each char:
   - If open bracket → push
   - If close bracket: if stack empty or top doesn't match → false. Pop.
3. Return stack is empty

---

## The One Trick
> "Stack remembers what you opened last — the last opened must be the first closed."

**Time**: O(n) | **Space**: O(n)
