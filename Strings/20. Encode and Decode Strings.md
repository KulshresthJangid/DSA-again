# Encode and Decode Strings

**Pattern**: Custom Serialization | **Difficulty**: Medium

---

## Like You're 5
You want to send a list of words through a pipe that only takes one long string.
You need a way to encode the list and decode it back perfectly — even if words contain special characters.
Solution: prefix each word with its length + a separator: `4#word3#cat`

---

## The Real Problem
Design encode/decode so `["lint","code","love","you"]` → single string → back to same list.

---

## How to Solve It
**Encode**: For each word, add `len(word)#word`
**Decode**: Read digits until `#`, that's the length, read that many chars as next word.

---

## The One Trick
> "Encode the length before each word — then decoding just reads that many characters."

**Time**: O(n) | **Space**: O(n)
