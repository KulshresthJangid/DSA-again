# Two Sum

**Pattern**: Hash Map | **Difficulty**: Easy

---

## Like You're 5
You have numbered blocks. Someone says "find two that add up to 9."
Instead of trying every pair, you keep a notebook. Each time you pick a block, you check: "did I already see the number I *need*?"
If yes — done. If no — write this number down and move on.

---

## The Real Problem
Given an array and a target, return indices of two numbers that sum to target.

**Example**: `nums=[2,7,11,15]`, target=`9` → `[0,1]` (2+7=9)

---

## How to Solve It
1. Make an empty map: `{number → index}`
2. For each number, calculate `need = target - number`
3. If `need` is already in the map → return `[map[need], current index]`
4. Otherwise add `{number → index}` to map

---

## See It Happen
```
nums=[2,7,11,15], target=9
i=0: num=2, need=7. Map empty. Add {2:0}
i=1: num=7, need=2. 2 IS in map! → return [0,1] ✓
```

---

## The One Trick
> "Don't search for a pair — ask if the partner you need has already walked by."

**Time**: O(n) | **Space**: O(n)
