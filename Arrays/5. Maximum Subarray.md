# Maximum Subarray (Kadane's Algorithm)

**Pattern**: Dynamic Programming / Greedy | **Difficulty**: Medium
**LeetCode**: [#53. Maximum Subarray](https://leetcode.com/problems/maximum-subarray/)

---

## Like You're 5
You're walking a path where each step gains or loses points. You want the stretch of path with the highest total score.
Rule: if your running total goes negative, drop it — start fresh from the next step. Negative baggage only hurts you.

---

## The Real Problem
Find the contiguous subarray with the largest sum.

**Example**: `[-2,1,-3,4,-1,2,1,-5,4]` → `6` (subarray `[4,-1,2,1]`)

---

## How to Solve It
1. `currentSum = nums[0]`, `maxSum = nums[0]`
2. For each number from index 1:
   - `currentSum = max(num, currentSum + num)` ← drop it or keep it
   - `maxSum = max(maxSum, currentSum)`
3. Return `maxSum`

---

## See It Happen
```
[-2,1,-3,4,-1,2,1,-5,4]
cur=-2, max=-2
cur=1,  max=1   (dropped -2, fresh start)
cur=-2, max=1
cur=4,  max=4   (dropped -2, fresh start)
cur=3,  max=4
cur=5,  max=5
cur=6,  max=6 ✓
```

---

## The One Trick
> "If carrying the past makes things worse, let it go — start over from here."

**Time**: O(n) | **Space**: O(1)
