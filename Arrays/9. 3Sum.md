# 3Sum

**Pattern**: Two Pointers | **Difficulty**: Medium
**LeetCode**: [#15. 3Sum](https://leetcode.com/problems/3sum/)

---

## Like You're 5
Find three friends whose ages add up to 0. Sort everyone by age first.
Pick one person, then use two other people (one from the youngest end, one from oldest end) and squeeze them toward each other until they work or cross.

---

## The Real Problem
Find all unique triplets in array that sum to zero.

**Example**: `[-1,0,1,2,-1,-4]` → `[[-1,-1,2],[-1,0,1]]`

---

## How to Solve It
1. Sort the array
2. For each index i (skip duplicates):
   - Set `left=i+1`, `right=end`
   - While left < right:
     - `sum = nums[i]+nums[left]+nums[right]`
     - If sum==0 → add triplet, move both pointers, skip duplicates
     - If sum<0 → left++ (need bigger)
     - If sum>0 → right-- (need smaller)

---

## See It Happen
```
sorted: [-4,-1,-1,0,1,2]
i=0 (val=-4): l=1,r=5 → sum=-3 → l++  ... no triplet
i=1 (val=-1): l=2,r=5 → sum=2 → r--
              l=2,r=4 → sum=0 → ADD [-1,-1,2], move both
              l=3,r=3 → stop
i=2 (val=-1): skip (same as i=1)
i=3 (val=0):  l=4,r=5 → sum=3 → r--  ... no triplet
```

---

## The One Trick
> "Sort first, fix one number, then two-pointer squeeze the rest."

**Time**: O(n²) | **Space**: O(1)
