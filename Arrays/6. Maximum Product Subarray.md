# Maximum Product Subarray

**Pattern**: Dynamic Programming (track min AND max) | **Difficulty**: Medium
**LeetCode**: [#152. Maximum Product Subarray](https://leetcode.com/problems/maximum-product-subarray/)

---

## Like You're 5
Like the sum version but multiplication has a twist: two negatives make a positive!
So a very negative number can flip and become the best answer later.
Track BOTH the biggest and smallest product at every step.

---

## The Real Problem
Find contiguous subarray with the largest product.

**Example**: `[2,3,-2,4]` → `6` (subarray `[2,3]`)

---

## How to Solve It
1. `maxProd = minProd = result = nums[0]`
2. For each number from index 1:
   - `candidates = (num, maxProd*num, minProd*num)`
   - `maxProd = max(candidates)`
   - `minProd = min(candidates)`
   - `result = max(result, maxProd)`
3. Return `result`

---

## See It Happen
```
[2,3,-2,4]
n=2:  max=2,  min=2,  res=2
n=3:  max=6,  min=3,  res=6
n=-2: max=-2, min=-12, res=6  (negative flipped!)
n=4:  max=-8, min=-48, res=6 ✓
```

---

## The One Trick
> "A negative × negative = positive — so always track the most negative product too, it might be your next big winner."

**Time**: O(n) | **Space**: O(1)
