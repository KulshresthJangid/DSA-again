# Find Minimum in Rotated Sorted Array

**Pattern**: Binary Search | **Difficulty**: Medium
**LeetCode**: [#153. Find Minimum in Rotated Sorted Array](https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/)

---

## Like You're 5
You lined up numbers from smallest to biggest, then someone rotated the line.
Like `[1,2,3,4,5]` became `[3,4,5,1,2]`.
The minimum is always at the "break point" where numbers suddenly drop.
Use binary search to find that break.

---

## The Real Problem
Given a rotated sorted array, find the minimum element.

**Example**: `[3,4,5,1,2]` → `1`

---

## How to Solve It
1. `left=0`, `right=len-1`
2. While left < right:
   - `mid = (left+right)//2`
   - If `nums[mid] > nums[right]`: min is in right half → `left = mid+1`
   - Else: min is in left half (including mid) → `right = mid`
3. Return `nums[left]`

---

## See It Happen
```
[3,4,5,1,2], l=0, r=4
mid=2, nums[2]=5 > nums[4]=2 → left=3
mid=3, nums[3]=1 < nums[4]=2 → right=3
l==r → return nums[3]=1 ✓
```

---

## The One Trick
> "Compare mid to right — if mid is bigger, the drop (minimum) is to the right of mid."

**Time**: O(log n) | **Space**: O(1)
