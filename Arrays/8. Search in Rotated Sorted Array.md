# Search in Rotated Sorted Array

**Pattern**: Binary Search | **Difficulty**: Medium

---

## Like You're 5
Same rotated array but now find a specific number.
At every mid-point, one half is always normally sorted. Figure out which half is sorted, check if your target is in that sorted half. If yes, go there. If no, go to the other half.

---

## The Real Problem
Search for target in a rotated sorted array. Return index or -1.

**Example**: `[4,5,6,7,0,1,2]`, target=`0` → `4`

---

## How to Solve It
1. `left=0`, `right=len-1`
2. While left ≤ right:
   - `mid = (left+right)//2`
   - If `nums[mid] == target` → return mid
   - If left half is sorted (`nums[left] <= nums[mid]`):
     - If target in `[nums[left], nums[mid]]` → `right=mid-1`
     - Else → `left=mid+1`
   - Else (right half is sorted):
     - If target in `[nums[mid], nums[right]]` → `left=mid+1`
     - Else → `right=mid-1`
3. Return -1

---

## The One Trick
> "One half is always cleanly sorted — check if target belongs there. If not, the answer is in the messy half."

**Time**: O(log n) | **Space**: O(1)
