# Contains Duplicate

**Pattern**: Hash Set | **Difficulty**: Easy
**LeetCode**: [#217. Contains Duplicate](https://leetcode.com/problems/contains-duplicate/)

---

## Like You're 5
You're handing out name tags at a party. If someone walks up and their name tag already exists in your pile — duplicate found!

---

## The Real Problem
Return true if any value appears more than once in the array.

**Example**: `[1,2,3,1]` → `true`

---

## How to Solve It
1. Create an empty set
2. For each number: if it's already in the set → return `true`
3. Otherwise add it to the set
4. If you finish the loop → return `false`

---

## See It Happen
```
[1,2,3,1]
1 → set={1}
2 → set={1,2}
3 → set={1,2,3}
1 → already in set! → true ✓
```

---

## The One Trick
> "A set can only hold unique items — trying to add a duplicate is your alarm bell."

**Time**: O(n) | **Space**: O(n)
