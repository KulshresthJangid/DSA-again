# Top K Frequent Elements

**Pattern**: Heap or Bucket Sort | **Difficulty**: Medium

---

## Like You're 5
Count how often each number appears. Then find the k numbers that appear most.
Method 1: Min-heap of size k — keep only top k frequent.
Method 2: Bucket sort by frequency — O(n).

---

## The Real Problem
Return k most frequent elements.

**Example**: `[1,1,1,2,2,3]`, k=2 → `[1,2]`

---

## How to Solve It (Bucket Sort)
1. Count frequencies
2. Buckets: index = frequency, value = list of numbers
3. Read buckets from end, collect k elements

---

## The One Trick
> "Bucket sort by frequency — index IS the frequency, read from highest bucket down."

**Time**: O(n) | **Space**: O(n)
