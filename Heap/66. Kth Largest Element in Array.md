# Kth Largest Element in Array

**Pattern**: Min-Heap of size k | **Difficulty**: Medium

---

## Like You're 5
Keep a "top k" leaderboard of size k. Use a min-heap — the smallest element on the leaderboard is at the top.
For each new number: if it's bigger than the smallest on the leaderboard, kick that one out and add the new number.
At the end, the heap's top = kth largest.

---

## The Real Problem
Return kth largest element (not kth distinct).

**Example**: `[3,2,1,5,6,4]`, k=2 → `5`

---

## How to Solve It
```
heap = []
for num in nums:
    heappush(heap, num)
    if len(heap) > k: heappop(heap)
return heap[0]
```

---

## The One Trick
> "Min-heap of size k: the minimum in it is the kth largest overall."

**Time**: O(n log k) | **Space**: O(k)
