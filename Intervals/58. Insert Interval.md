# Insert Interval

**Pattern**: Linear Scan + Merge | **Difficulty**: Medium

---

## Like You're 5
You have sorted non-overlapping intervals and need to insert a new one.
Three phases: add everything that ends before new interval starts, merge everything that overlaps, add the rest.

---

## The Real Problem
Insert a new interval into sorted non-overlapping intervals and merge if needed.

**Example**: `[[1,3],[6,9]]`, insert `[2,5]` → `[[1,5],[6,9]]`

---

## How to Solve It
```
result = []
i = 0
# Phase 1: add all intervals that end before new interval starts
while i<n and intervals[i][1] < new[0]: result.append(intervals[i]); i++
# Phase 2: merge overlapping
while i<n and intervals[i][0] <= new[1]:
    new = [min(new[0],intervals[i][0]), max(new[1],intervals[i][1])]; i++
result.append(new)
# Phase 3: add rest
result.extend(intervals[i:])
```

---

## The One Trick
> "Three phases: before, overlapping (merge), after. Each has a clear condition."

**Time**: O(n) | **Space**: O(n)
