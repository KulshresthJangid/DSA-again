# Non-overlapping Intervals

**Pattern**: Greedy | **Difficulty**: Medium
**LeetCode**: [#435. Non-overlapping Intervals](https://leetcode.com/problems/non-overlapping-intervals/)

---

## Like You're 5
Remove the minimum number of intervals so none overlap. Sort by end time. Keep an interval if it doesn't conflict with the previous kept one. Remove those that do conflict (greedily keep the one with earlier end — it leaves more room).

---

## The Real Problem
Return min number of intervals to remove to make rest non-overlapping.

---

## How to Solve It
1. Sort by end time
2. `end = -inf`, `removed = 0`
3. For each interval:
   - If start >= end: keep it, update end
   - Else: remove it (increment count)
4. Return count

---

## The One Trick
> "Sort by end time, greedily keep non-overlapping intervals — earlier end = more future room."

**Time**: O(n log n) | **Space**: O(1)
