# Merge Intervals

**Pattern**: Sort + Greedy Merge | **Difficulty**: Medium
**LeetCode**: [#56. Merge Intervals](https://leetcode.com/problems/merge-intervals/)

---

## Like You're 5
You have time blocks that might overlap. Sort them by start time. Merge two blocks if one starts before the other ends — their combined block is from the earlier start to the later end.

---

## The Real Problem
Merge all overlapping intervals.

**Example**: `[[1,3],[2,6],[8,10],[15,18]]` → `[[1,6],[8,10],[15,18]]`

---

## How to Solve It
1. Sort by start
2. result = [first interval]
3. For each interval:
   - If overlaps with last in result: extend end = max(both ends)
   - Else: append as new interval

---

## The One Trick
> "Sort, then greedily merge: if current start ≤ last result's end, they overlap."

**Time**: O(n log n) | **Space**: O(n)
