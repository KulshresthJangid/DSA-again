# Meeting Rooms II

**Pattern**: Min-Heap (room tracking) | **Difficulty**: Medium

---

## Like You're 5
How many rooms do you need minimum? Sort meetings by start. Use a heap of end-times.
When a meeting starts, check if the earliest-ending room is free. If yes, reuse it. If no, book a new room.

---

## The Real Problem
Return minimum number of conference rooms needed.

---

## How to Solve It
1. Sort by start time
2. Min-heap of end times
3. For each meeting:
   - If `heap[0] <= start`: pop (reuse room)
   - Push end time
4. Return heap size

---

## The One Trick
> "Heap tracks when each room frees up. If the earliest-free room is still busy — you need a new room."

**Time**: O(n log n) | **Space**: O(n)
