# Meeting Rooms

**Pattern**: Sort + Overlap Check | **Difficulty**: Easy
**LeetCode**: [#252. Meeting Rooms](https://leetcode.com/problems/meeting-rooms/) *(Premium)*

---

## Like You're 5
Can one person attend all meetings? Sort meetings by start time. If any meeting starts before the previous one ends — conflict!

---

## The Real Problem
Given intervals, return true if a person can attend all (no overlaps).

**Example**: `[[0,30],[5,10],[15,20]]` → `false` (0-30 overlaps with 5-10)

---

## How to Solve It
1. Sort by start time
2. For each meeting from index 1:
   - If `start[i] < end[i-1]` → return false
3. Return true

---

## The One Trick
> "Sort by start. Any meeting starting before previous ends = overlap."

**Time**: O(n log n) | **Space**: O(1)
