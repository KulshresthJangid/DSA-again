# Clone Graph

**Pattern**: DFS + Hash Map | **Difficulty**: Medium

---

## Like You're 5
You're photocopying a web of friends. Each person points to other people.
When you copy a person, remember you already copied them (in a map). If you see them again, use the copy you already made — don't copy twice.

---

## The Real Problem
Return a deep copy of a connected undirected graph.

---

## How to Solve It
1. `visited = {}` (original node → cloned node)
2. DFS(node):
   - If node in visited → return visited[node]
   - Create clone, add to visited
   - For each neighbor: clone.neighbors.append(DFS(neighbor))
   - Return clone

---

## The One Trick
> "Map original → clone to avoid infinite loops on cycles."

**Time**: O(V+E) | **Space**: O(V)
