# Alien Dictionary

**Pattern**: Topological Sort | **Difficulty**: Hard

---

## Like You're 5
You have words in alien alphabetical order. By comparing adjacent words, you learn some letter ordering rules: "a comes before b."
Build a graph of these rules, then topological sort to find the full alphabet order. If there's a cycle → invalid.

---

## The Real Problem
Given sorted alien words, find character ordering (or return "" if invalid).

---

## How to Solve It
1. Compare adjacent words letter by letter — first diff gives an edge
2. Topological sort (Kahn's or DFS)
3. Cycle → return ""

---

## The One Trick
> "Adjacent words reveal one ordering rule each. Topo-sort assembles all rules into a sequence."

**Time**: O(C) — C = total characters | **Space**: O(1) (26 chars max)
