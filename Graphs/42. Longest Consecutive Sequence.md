# Longest Consecutive Sequence

**Pattern**: Hash Set | **Difficulty**: Medium
**LeetCode**: [#128. Longest Consecutive Sequence](https://leetcode.com/problems/longest-consecutive-sequence/)

---

## Like You're 5
Find the longest chain of consecutive numbers in an unsorted array.
Put all numbers in a set. For each number, only start counting a chain if it's the beginning (no num-1 in set). Then extend as far as possible.

---

## The Real Problem
Return the length of the longest consecutive sequence. Must run in O(n).

**Example**: `[100,4,200,1,3,2]` → `4` (1,2,3,4)

---

## How to Solve It
1. Put all numbers in a HashSet
2. For each num: if `num-1` NOT in set (it's a start):
   - Count up: how far does the chain extend?
   - Update max length

---

## The One Trick
> "Only start a chain from the smallest number in that sequence — skip the rest to keep it O(n)."

**Time**: O(n) | **Space**: O(n)
