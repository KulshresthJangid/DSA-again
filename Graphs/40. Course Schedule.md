# Course Schedule

**Pattern**: Cycle Detection in Directed Graph (DFS) | **Difficulty**: Medium

---

## Like You're 5
You have courses and prerequisites. Can you take all of them?
Only impossible if there's a circular dependency: A needs B, B needs C, C needs A — infinite loop!
Detect cycles in the dependency graph.

---

## The Real Problem
Return true if it's possible to finish all courses given prerequisites (no cycle = possible).

---

## How to Solve It
1. Build adjacency list
2. DFS each node. Track: visiting (in-progress), visited (done)
3. If you hit a node currently being visited → cycle → return false
4. If all nodes finish without cycle → return true

---

## The One Trick
> "Three states: unvisited, visiting, visited. Hitting a 'visiting' node = cycle."

**Time**: O(V+E) | **Space**: O(V+E)
