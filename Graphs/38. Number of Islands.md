# Number of Islands

**Pattern**: DFS/BFS Grid Flood Fill | **Difficulty**: Medium

---

## Like You're 5
You have a map with land ('1') and water ('0'). Count the separate landmasses.
When you find a land cell, flood-fill it (mark visited) to erase the entire island. Each flood-fill = one island.

---

## The Real Problem
Count islands (connected '1's) in a 2D grid.

---

## How to Solve It
1. For each cell:
   - If `grid[r][c] == '1'`: count++, run DFS to sink the island
2. DFS: mark cell as '0', recurse on 4 neighbors if they're '1'

---

## The One Trick
> "Flood-fill destroys each island as you count it — no need to track visited separately."

**Time**: O(m×n) | **Space**: O(m×n)
