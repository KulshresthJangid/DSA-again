# Min Stack

**Pattern**: Stack with auxiliary min-tracking | **Difficulty**: Medium
**LeetCode**: [#155. Min Stack](https://leetcode.com/problems/min-stack/)

---

## Like You're 5
A normal stack, but getMin() must be O(1) always.
Keep a second stack that tracks the minimum at each state. When you push, also push the new min to the min-stack. When you pop, pop from both.

---

## The Real Problem
Design a stack with push, pop, top, and getMin — all O(1).

---

## How to Solve It
```
stack = []
minStack = []

push(val):
    stack.append(val)
    minStack.append(min(val, minStack[-1] if minStack else val))

pop():
    stack.pop()
    minStack.pop()

getMin(): return minStack[-1]
```

---

## The One Trick
> "Parallel min-stack records the 'running minimum' at every push. Pop both together."

**Time**: O(1) all ops | **Space**: O(n)
