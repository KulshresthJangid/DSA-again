# Largest Rectangle in Histogram

**Pattern**: Monotonic Stack | **Difficulty**: Hard
**LeetCode**: [#84. Largest Rectangle in Histogram](https://leetcode.com/problems/largest-rectangle-in-histogram/)

---

## Like You're 5
Each bar has a height. Find the biggest rectangle you can draw using consecutive bars.
For each bar, find how far left and right it can extend (while all bars are at least as tall).
Monotonic stack: for each bar, pop all taller bars on the left when you hit a shorter one — compute their max rectangles.

---

## The Real Problem
Find max area rectangle in histogram.

**Example**: `[2,1,5,6,2,3]` → `10` (bars of height 5 and 6)

---

## How to Solve It
```
stack = []  # (index, height)
maxArea = 0
for i, h in enumerate(heights):
    start = i
    while stack and stack[-1][1] > h:
        idx, height = stack.pop()
        maxArea = max(maxArea, height * (i - idx))
        start = idx
    stack.append((start, h))
for idx, height in stack:
    maxArea = max(maxArea, height * (len(heights) - idx))
return maxArea
```

---

## The One Trick
> "A bar's rectangle extends as far left as all taller bars that were popped. Track the 'extended' start."

**Time**: O(n) | **Space**: O(n)
