# Car Fleet

**Pattern**: Monotonic Stack / Sort | **Difficulty**: Medium
**LeetCode**: [#853. Car Fleet](https://leetcode.com/problems/car-fleet/)

---

## Like You're 5
Cars drive to a destination. Faster cars catch up to slower ones and form a fleet (they can't pass).
Sort by position (closest to target first). Compute time each car needs. If a faster car catches the one ahead, they merge into one fleet.

---

## The Real Problem
Return number of car fleets that arrive at target.

---

## How to Solve It
1. Sort cars by position descending (closest to target first)
2. Compute time = (target - pos) / speed for each
3. Use stack: if current time > stack top, it's a new fleet (push). Else it joins the fleet ahead (skip).
4. Return stack size

---

## The One Trick
> "Sort by position descending. Larger time = slower car = new fleet (can't catch up)."

**Time**: O(n log n) | **Space**: O(n)
