# Daily Temperatures

**Pattern**: Monotonic Stack | **Difficulty**: Medium
**LeetCode**: [#739. Daily Temperatures](https://leetcode.com/problems/daily-temperatures/)

---

## Like You're 5
For each day, how many days until a warmer day?
Use a stack to track "waiting" days. When a warmer day arrives, resolve all waiting days that are colder.

---

## The Real Problem
Return array where `result[i]` = days until a warmer temperature (0 if none).

**Example**: `[73,74,75,71,69,72,76,73]` → `[1,1,4,2,1,1,0,0]`

---

## How to Solve It
```
stack = []  # indices of unresolved days
result = [0] * n
for i, temp in enumerate(temps):
    while stack and temps[stack[-1]] < temp:
        j = stack.pop()
        result[j] = i - j
    stack.append(i)
return result
```

---

## The One Trick
> "Monotonic stack: push indices, pop when a warmer day arrives. Difference of indices = days waited."

**Time**: O(n) | **Space**: O(n)
