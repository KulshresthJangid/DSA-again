# Missing Number

**Pattern**: XOR or Math | **Difficulty**: Easy
**LeetCode**: [#268. Missing Number](https://leetcode.com/problems/missing-number/)

---

## Like You're 5
You have numbers 0 to n with one missing. The sum of 0..n is `n*(n+1)/2`. Subtract the actual sum — the difference is the missing number.
Or: XOR all indices 0..n with all values — duplicates cancel, missing number remains.

---

## The Real Problem
Find the missing number in array containing n distinct numbers from 0 to n.

**Example**: `[3,0,1]` → `2`

---

## How to Solve It (Math)
```
return n*(n+1)//2 - sum(nums)
```

---

## The One Trick
> "Expected sum minus actual sum = missing number. One line."

**Time**: O(n) | **Space**: O(1)
