# Counting Bits

**Pattern**: DP + Bit Trick | **Difficulty**: Easy
**LeetCode**: [#338. Counting Bits](https://leetcode.com/problems/counting-bits/)

---

## Like You're 5
For each number from 0 to n, count its 1-bits.
Pattern: `dp[i] = dp[i>>1] + (i&1)`
(Shift right removes last bit; the number of 1s in the rest is already computed. Just add whether last bit is 1.)

---

## The Real Problem
Return array of 1-bit counts for all numbers 0 to n.

**Example**: n=5 → `[0,1,1,2,1,2]`

---

## How to Solve It
```
dp = [0] * (n+1)
for i in range(1, n+1):
    dp[i] = dp[i>>1] + (i&1)
return dp
```

---

## The One Trick
> "Bit count of i = bit count of (i//2) + last bit of i. Builds on previously computed answers."

**Time**: O(n) | **Space**: O(n)
