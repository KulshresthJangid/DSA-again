# Reverse Bits

**Pattern**: Bit Manipulation | **Difficulty**: Easy
**LeetCode**: [#190. Reverse Bits](https://leetcode.com/problems/reverse-bits/)

---

## Like You're 5
Take the 32-bit binary number, flip it left-to-right.
Build the result bit by bit: take the last bit of n, put it in the next position of result, shift both.

---

## The Real Problem
Reverse bits of a 32-bit unsigned integer.

---

## How to Solve It
```
result = 0
for _ in range(32):
    result = (result << 1) | (n & 1)
    n >>= 1
return result
```

---

## The One Trick
> "Peel bits from n one at a time, attach to result from the other direction."

**Time**: O(1) — fixed 32 iterations | **Space**: O(1)
